# Algorithm Visualiser In Winforms
> An educational program to teach basic searching and sorting algorithms inspired by [The Sound of Sorting](https://panthema.net/2013/sound-of-sorting/).

## Features
- [X] Bubble Sort
- [X] Bogo Sort (peak)
- [X] Insertion Sort
- [X] Menu
- [ ] Speed/manual frame control
- [ ] Styles (see array values)

## Major issue
From what I can tell there is no good way to produce audio based on the selected array index's value as quickly as needed.
